# 📒 我的记账本

一个简单好用的手机记账网页。在手机上打开网址就能记账，不需要下载 App，不经过任何服务器，**账目数据只存在你自己的手机里**。

## ✨ 功能

- **记支出**：主页面输金额 → 点"确定" → 选这笔钱花在哪（用途标签）→ 保存
- **日期自动记录**，也可以手动改
- **自定义标签**：餐饮、交通、购物……标签随便你自己加，还能选图标和颜色
- **明细列表**：按天分组，点开任意一笔能看到用途和备注
- **本月统计**：本月花了多少、记了几笔
- **备份/恢复**：定期导出一键文件，换手机也能把账搬过去
- **添加到主屏幕**：像真 App 一样用，还能离线记账

## 📱 怎么在手机上用（部署到 GitHub Pages）

跟着下面做一遍，大概 15 分钟，全程用浏览器点鼠标，不需要装任何软件。

### 第一步：注册 GitHub 账号

1. 手机或电脑浏览器打开 **https://github.com**
2. 点右上角 **Sign up**（注册）
3. 按提示填邮箱、设密码、起一个用户名，然后按它要求验证邮箱
4. 注册成功后，登录你的 GitHub

### 第二步：创建一个仓库（就是网页的家）

1. 登录后，点右上角 **+** 号 → **New repository**
2. **Repository name** 填：`jizhang`（一定要是这个，网址才能对）
3. 下面选 **Public**（公开，免费）即可
4. 点绿色按钮 **Create repository** 创建

### 第三步：把记账本文件传上去

1. 创建好后会进入一个仓库页面，点上面的 **Add file** → **Upload files**
2. 把 `jizhang` 文件夹里的这 10 个文件**全部选中拖进去**（或点"choose your files"选择）：
   - `index.html`　`style.css`　`app.js`
   - `manifest.json`　`sw.js`
   - `icon.svg`　`icon.png`　`icon-192.png`　`icon-512.png`
   - `gen-icons.ps1`（可传可不传，只是生成图标的工具）
3. 往下滚，点绿色按钮 **Commit changes**（提交）

### 第四步：开启 Pages（让网页上线）

1. 回到仓库主页，点顶部的 **Settings**（设置）
2. 左侧菜单找到 **Pages**（网页发布）
3. **Branch** 选 `main`，文件夹选 `/ (root)`，点 **Save**
4. 等 1~3 分钟，刷新页面，顶部会出现一行绿字：
   **Your site is live at `https://你的用户名.github.io/jizhang/`**

### 第五步：手机打开

- 在手机浏览器输入：**`https://你的用户名.github.io/jizhang/`**
- 微信、百度、Safari 都能打开。**建议固定用一个入口**（因为不同浏览器里的账目是分开的）

### 第六步：添加到主屏幕（当成 App 用）

**iPhone（Safari）**：打开网址 → 点底部中间的 **分享**（方框箭头图标）→ 向下滑点 **添加到主屏幕** → 添加。
以后点桌面上的"记账本"图标就能打开，**断网也能记账**。

**Android（Chrome/百度浏览器）**：打开网址 → 右上角菜单 → **添加到主屏幕**。

## 💾 数据备份（重要！）

账目只存在手机的浏览器里，**清理浏览器缓存或卸载后数据会丢**。建议：

- 定期打开 **设置 → 数据备份 → 导出备份文件**，把下载的 `.json` 文件存到微信"文件传输助手"或网盘
- 换手机时：旧手机**导出**备份文件 → 新手机打开同一个网址 → **设置 → 数据备份 → 从备份文件恢复**

## ☁️ 云同步（让微信 / Safari / 换手机用同一份账）

默认账目存在手机浏览器里，微信和 Safari 是分开的。想任何地方打开都是同一份账，就开云同步：

1. 电脑浏览器打开 **https://github.com/settings/tokens**（要先登录 GitHub）
2. 点 **Generate new token**（Classic / 经典令牌），名称随便填，把 **repo** 这一项勾上，往下滚点 **Generate token**
3. **立刻复制**出现的 token（`ghp_` 开头，只显示这一次）
4. 手机上打开记账本 → **设置 → 云同步**，填：
   - GitHub 用户名：你的用户名（如 `yx-1-s`）
   - 数据仓库名：`jizhang-data`（会自动创建私有仓库，不用你手动建）
   - Token：粘贴刚复制的
5. 点 **保存云同步设置**，看到状态变"已同步"就成功了

之后每记一笔都会自动上传。换手机时：新手机打开网址 → 设置 → 云同步 → 从云端拉取。

**安全提醒**：token 只存在你自己的手机里。担心泄露的话，随时可以去 GitHub 的 token 页面删除它（删除后云同步失效，需要重新生成）。

## ❓ 常见问题

**打开是空白/旧的版本？**
刷新一下页面，或删掉网页后重新打开。更新过网页后，第一次打开可能还是旧缓存，刷新即可。

**想改标签名字或颜色？**
**设置 → 标签管理**，点标签可以编辑，点旁边的 ✕ 删除。

**记错了怎么删？**
**明细**页点开那笔账 → **删除这笔账**。

**账记在哪个浏览器里，就只能在那个浏览器里看。**
微信里记的和 Safari 里记的是两套数据，这是浏览器的安全机制，别混着用。

## 🛠 本地先试试（可选）

不用上网也能先体验：双击 `index.html` 在浏览器打开就能记账（只是"添加到主屏幕"和离线功能需要部署后才有）。
